What I Built

  • ผมสร้างเว็บที่จะไว้ใช้พัฒนาทักษะ ฝีมือ และความสามารถ และใช้เก็บผลงานต่าง ๆ ของผม
  • มีส่วนประกอบสำคัญ ได้แก่
    ส่วนเฮดเดอร์ คือส่วน รูปและข้อมูลของผม
    ส่วนเมนหลัก คือส่วนที่แสดงเนื้อหาหลักของเว็บไซต์(Requirements)
    ส่วนท้าย หรือส่วนเครดิต ช่องทางการติดต่อของผม
  • การที่เว็บนี้รันอยู่บนเครื่องผม ส่วนตัวผมก็คิดว่ามี Client และ Server เกิดขึ้นครับ เพราะเครื่องที่ขอหนา้เว็บคือเครื่องผมและเครื่องที่ขอคือเครื่องผมเองครับ(ถูกหรือผิดอาจารย์สามารถบอกผมได้เลยนะครับ)


How I Built this

  • เว็บไซต์นี้สร้างจากทักษะของผม และมีไว้เพื่อใช้ฝึกฝน พัฒนาทักษะการเขียนโค้ด และเก็บผมงานด้านต่าง ๆ ของผม
  • เว็บไซต์นี้ถูกเขียนขึ้นด้วยการพิมพ์มือทั้งหมด จะมีการใช้เอไอแค่การสืบค้นข้อมูลเท่านั้น
  • เครื่องมือในการสืบค้นข้อมูล ก็มีทั้งเพื่อนร่วมชั้น บนเว็บไซต์ต่าง ๆ และบอทเอไอ เช่น cloaude code

Reflection

ปัญหาหรือความททายที่พบ และวิธีรับมือ :

ปัญหาที่พบแรก ๆ คือ การตกแต่งเพราะผมมักจะจำโค้ดฟร้อน หรือโค้ดกรอบไม่ได้ แก้ไขด้วยการเปิดไฟล์โมดุล ไฟล์สไลด์ และงานเก่าๆที่ผมโยนขึ้นserverไว้ เปิดดูและทำควบคู่กันไปครับ และผมอยากจะตกแต่งให้เว็บมีลวดลายมากกว่านี้ แต่ตอนนี้ทักษะยังไม่ถึงครับ น่าจะต้องไปฟาร์มความรู้เพิ่มในยูทูปครับ แล้วก้ผมโหลดฟ้อนมาครับ แต่มันไม่ยอมลงให้ผมงงมากกครับ ต้องไปหาวิธีแก้เพราะไม่น่าทัน
